# 0001: 既存 MVP を退避し、新規設計から再構築する

日付: 2026-05-04

## 決定

既存の分身AI MVP 実装は `legacy_assets/20260504_004800_existing_assets/` に退避し、新規バックエンドは Laravel の fresh skeleton から API-first で再設計する。

## 背景

旧実装は画面主導の CRUD とバブル UI が中心で、今後のバックエンド開発に必要な API 契約、tenant 単位の分離、隠し記憶の権限表現、タグ・カテゴリの正規化が設計として固定されていなかった。

## 運用ルール

- legacy 配下の実装を直接改修して進めない。
- legacy は要件確認や復元が必要な場合だけ参照する。
- 新規側の正式 task は `task_board.md` に 1 つだけ置く。
- 新しく思いついた論点はすぐ実装せず、追加 task 候補に積む。
