EMOTIONAL VALUE

忘れていた自分に、また会える。

昔の夢、初恋、学生時代、家族との会話、悩んでいた時期、人生が変わった瞬間。メモリルでは、それらを“感情ごと”記録できます。

夢

昔の夢を残す

当時なりたかったもの、諦めた理由、まだ残っている気持ちまで保存します。

恋

初恋や青春を残す

名前だけではなく、その時の高鳴りや言えなかった言葉も記憶として残せます。

家

家族との時間を残す

何気ない会話、子どもの成長、親の言葉を未来の自分や大切な人へ渡せます。

MEMORY AVATAR

AIが、あなたになっていく。

普通のAIは、誰にでも同じように答えます。メモリルのAIは、あなたが話した記憶をもとに、話し方、感情傾向、思考パターン、大切にしている価値観を少しずつ理解していきます。

1 話し方や口ぐせ
2 喜びや傷つきのパターン
3 人生経験と価値観
4 あなたが大切にしてきた人や場所
最近また自信がなくなってきた。
大学の発表前にも同じ気持ちを書いていました。あの時は、準備を小さく分けたことで落ち着いていました。
そういえば、あの時も怖かった。
でも最後には「怖いまま進めた」と記録しています。今回も、まず一つだけ進めてみませんか。

USE CASES

こんな使い方ができます。

メモリルは、自己理解、家族の記録、教育、カウンセリング、終活まで、人生の記憶を扱う場面で使えます。

自

自己理解ツール

感情の変化を見返し、自分が何に傷つき、何に喜び、どう変化してきたかを知る。

家

家族アルバム

人生の出来事や家族との会話を、大切な人へ残せる記録空間にする。

学

教育現場

子どもたちの日々の記録、感情変化、成長、自分を表現する力を蓄積する。

癒

感情整理の支援

過去の自分との対話を通じて、ジャーナリングやカウンセリングの補助に使う。

声

終活ツール

声や想い、人生の記録を未来へ残し、家族があとから振り返れるようにする。

友

思い出共有

友だち、同級生、仲間と懐かしい記憶を見ながら、自然に会話を生む。

PRIVATE MEMORY

見られたくない記憶は、守れる。

本音や弱さも残せるように、シークレットモード、ロック機能、記憶ごとの公開制御を用意します。自分だけの記憶と、共有したい記憶を分けて扱えます。
